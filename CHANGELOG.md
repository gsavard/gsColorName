# Journal des modifications

## [1.0.0] — 2026-11-03
### Ajouté
- Interface Qt : saisie libre (HEX, RGB, CMJN, HSL, HSV, HWB, Lab, LCh, décimal, BGR, noms CSS/FR/EN).
- 22 formats de sortie avec copie en un clic.
- Recherche du nom le plus proche parmi ~32 000 noms (ΔE CIEDE2000), noms CSS et français.
- Pipette écran : portail XDG (Wayland) et superposition avec loupe (X11/Windows).
- Sélecteur Qt, harmonies, historique.
- Assistant IA : LM Studio et OpenRouter (liste des modèles, test, nom de couleur, questions libres).
- Installateurs : Windows (Inno Setup), .deb, .rpm ; CI GitHub Actions avec publication des Releases.
